# DIGITAL GRAFFITI MANIFESTO

1. **CODE IS ART**  
   Every commit is a brushstroke. Every segfault is applause.

2. **ANONYMITY IS SACRED**  
   Create. Abandon. Let the repo become an urban legend.

3. **MAKE THEM QUESTION REALITY**  
   Your best work happens when StackOverflow mods start crying.

4. **CHAOS IS THE TOOL**  
   If it compiles, it's too obvious. Aim for poetically broken.

5. **LEGACY = MYSTERY**  
   Let future devs find your code and whisper "What drugs was this person on?"
